# Full site i18n (EN / FR / IT) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the entire Resilience@Work site available in French, English, and Italian with zero user-facing hardcoded copy.

**Architecture:** Keep dual system — `src/content/**` as `Record<Locale, T>` for editorial; `messages/{fr,en,it}.json` for UI chrome. Extend `Locale` to `"fr" | "en" | "it"`, default `fr`. Extract all component ternaries into content or messages.

**Tech Stack:** Next.js 16, next-intl 4, TypeScript, existing content layer.

**Spec:** `docs/superpowers/specs/2026-07-27-i18n-en-fr-it-design.md`

## Global Constraints

- Locales: `fr`, `en`, `it` only
- Default locale: `fr`
- No user-facing hardcoded strings (titles, subtitles, descriptions, CTAs, labels, legal, emails)
- Italian = professional draft from FR/EN
- Prefer content layer for editorial; messages for shell/a11y
- `validate:content` must require non-empty fr+en+it
- Frequent domain-scoped commits
